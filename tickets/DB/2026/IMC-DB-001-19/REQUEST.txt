EVIDENZA DA VERIFICARE NEL DOM
Nel DOM live le nazionali non usano il normale handler club del parser storico. Nei Results sono presenti elementi `#homeTeam` / `#awayTeam` con handler del tipo:
`MENU_association_draw('646525')` -> Jamaica
`MENU_association_draw('646512')` -> France
`MENU_association_draw('646548')` -> Russia
`MENU_association_draw('646504')` -> Czech Republic
`MENU_association_draw('646556')` -> Trinidad & Tobago
`MENU_association_draw('646555')` -> Sweden
`MENU_association_draw('646518')` -> Hungary
`MENU_association_draw('646537')` -> Morocco
`MENU_association_draw('646506')` -> Ecuador
`MENU_association_draw('646501')` -> Costa Rica
`MENU_association_draw('646495')` -> Canada

Le fixture hanno invece handler Match Report separati, per esempio:
`MATCHREPORT_downloadScoreCentre('380661095', 1)` per Iraq-Russia.

Questa distinzione è fondamentale: verificare che il codice non stia confondendo fixture ID (`380...`) con association/national-team ID (`646...`).
