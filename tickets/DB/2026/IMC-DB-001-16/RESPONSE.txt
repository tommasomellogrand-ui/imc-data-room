======================================================================
5. CANONICAL CONTEXT PIPELINE
======================================================================

Pipeline obbligatoria:
DOM raw
-> rawContext()
-> canonicalContext(raw, worldStructure)
-> validateCanonicalContext()
-> competitionKey(canonical)
-> resultRows()
-> fingerprint()

Non deve più esistere un unico context() che mescola lettura DOM e semantica IMC.

5.1 macro(action)

Può restare semanticamente invariata:
DOMESTIC:
league, leaguecup, leagueshield, charityshield, playoff

INTERNATIONAL:
smfacup, smfashield, supercup

NATIONS:
interqualifier, worldcup

Unknown action -> null / validation failure.

5.2 canonicalContext(raw)

PSEUDOCODE:

function canonicalContext(raw){
  const structure = worldStructure(S.gw);
  const action = norm(raw.action_raw);
  const group = macro(action);

  if(!group || !action) throw Error('Context action non canonico');

  let country = null;
  let division = null;

  if(group === 'INTERNATIONAL' || group === 'NATIONS'){
    return {sm_action:action, sm_country:null, sm_division:null, competition_group:group};
  }

  if(structure === 'SINGLE'){
    country = null;
    division = action === 'league' ? canonicalDivision(raw) : null;
  }else{
    country = canonicalCountry(raw);
    division = action === 'league' ? canonicalDivision(raw) : null;
  }

  return {...};
}

5.3 canonicalCountry(raw)

MULTI only.
Priority:
1. pager country_raw, se non CUS e non vuoto;
2. selected country value;
3. fail validation.

NON usare selected text come stored code.
Il testo serve solo diagnostic/UI.

CUS:
non è mai una country IMC canonica.
Se structure=MULTI e country candidate=CUS -> validation error.
Se structure=SINGLE -> ignored as technical DOM token.

5.4 canonicalDivision(raw)

Solo League.
Priority:
1. pager division_raw;
2. selected division value;
3. parse selected text `Divisione N` / `Division N`;
4. fail validation per League.

Output canonico:
string/number division N senza label.

5.5 competition_group_name

Conservare comportamento attuale solo se il group header visibile è scoped dentro resultsRoot() e rappresenta realmente una fase/group.
Per League standard: null.
Per grouped international/nations: nome gruppo visibile, es. Girone A.

6. COMPETITION KEY GRAMMAR
======================================================================

competitionKey() V1 va sostituita da builder esplicito.
Nessun `.filter(x=>clean(x))` per decidere la semantica.

PSEUDOCODE:

function competitionKey(c){
  const gw=S.gw;
  const a=c.sm_action;
  const g=c.competition_group;
  const structure=worldStructure(gw);

  if(g==='INTERNATIONAL' || g==='NATIONS')
    return `${gw}|${g}|${a}`;

  if(g!=='DOMESTIC') throw Error('Competition group non canonico');

  if(structure==='SINGLE'){
    if(a==='league') return `${gw}|DOMESTIC|league|${requiredDivision(c)}`;
    return `${gw}|DOMESTIC|${a}`;
  }

  const country=requiredCountry(c);
  if(a==='league') return `${gw}|${country}|DOMESTIC|league|${requiredDivision(c)}`;
  return `${gw}|${country}|DOMESTIC|${a}`;
}

GRAMMATICA:

SINGLE League:
GW|DOMESTIC|league|DIV

SINGLE DOMESTIC non-League:
GW|DOMESTIC|ACTION

MULTI League:
GW|COUNTRY|DOMESTIC|league|DIV

MULTI DOMESTIC non-League:
GW|COUNTRY|DOMESTIC|ACTION

INTERNATIONAL:
GW|INTERNATIONAL|ACTION

NATIONS:
GW|NATIONS|ACTION

CUS non può comparire in nessuna key canonica.

9.3 team(row, side)

PSEUDOCODE:

function team(row,side){
  const node = row.querySelector(side==='home' ? '#homeTeam' : '#awayTeam');
  const name = clean(node?.textContent)||null;
  const id = parseWorldClubId(node);

  if(id) return {name,id,status:'RESOLVED_DOM',controlled:false};

  const current=currentControlledClub();
  if(name && current && norm(name)===current.normalizedName){
    const mapped=currentClubWorldIdResolver(S.gw,name);
    if(mapped) return {name,id:mapped,status:'RESOLVED_MAPPING',controlled:true};
    return {name,id:null,status:'UNRESOLVED_CONTROLLED_CLUB',controlled:true};
  }

  return {name,id:null,status:'UNRESOLVED_DOM_ID',controlled:false};
}

9.4 currentClubWorldIdResolver

INTERFACE ONLY in V2.

Current IMC Game World Club Mapping non è sufficiente per i casi auditati:

- GW007 mapping corrente non copre il mondo.

Policy prima release:

Non bloccare l'intero importer per controlled-club unresolved; preservare comportamento business attuale (null) ma renderlo esplicito nel log/runtime.

Future:
quando esisterà mapping world-local certificata, resolver può valorizzare senza cambiare resultRows schema.
