======================================================================
1. ROOT CAUSE HTTP 500
======================================================================

Il failure HTTP 500 del Gateway non era causato dal DROP delle tabelle CORE né dalla route imc_managers in sé.

Root cause reale:
- api/imc-gateway/index.php esegue require_once __DIR__.'/database.php';
- il workflow pubblico deploy-website-aruba.yml pubblicava index.php/config.php ma NON includeva api/imc-gateway/database.php;
- il runtime Aruba andava quindi in fatal error PHP al bootstrap, prima del normale out() JSON del Gateway;
- per questo il 500 aveva body vuoto e colpiva anche route non-CORE.

Conclusione: deployment incompleto di una dipendenza obbligatoria del Gateway.
