IMC SYSTEM AUTHORITY POLICY

1. MySQL Aruba è la fonte dati autoritativa IMC.
2. Supabase è un ponte tecnico verso MySQL Aruba e non è fonte dati autoritativa.
3. GitHub è la fonte autoritativa per codice, sito e gateway.
4. Il repository IMC Data Room su GitHub è fonte autoritativa per ticket e knowledge documentale; Aruba è la copia pubblicata consultabile online.
5. Nessun documento pubblico deve contenere secret, token, password o credenziali.
